CAS AUTOLASE 更新（training-18.1）

1. ZIPを展開します。
2. サーバーで使っている同名の旧.mizを別名でバックアップします。
3. ZIP内のpersistant_and_dynamic_traning.mizでサーバーのミッションを置き換え、ミッションを再開始します。
   通常の配置先: Saved Games\DCS.dcs_serverrelease\Missions
4. Apacheで Task: CAS → Laser 1688（または1687 / 1686）を受注します。
5. 受注しただけでは照射しません。攻撃準備ができたら、F10の Dynamic Training → CAS JTAC → Request laser を選びます。
   項目がMoreの次ページにある場合はMoreを開いてください。
6. 「CAS JTAC: Lasing ... LASER ...」が表示されたら、選択コードをLSTで捕捉して攻撃します。
7. 止める場合は同じCAS JTAC内の Stop laser。再開は Request laser で依頼し直します。
   標準JTACとの無線チェックイン、9-line、133 MHz等への同調は不要です。

依頼中のJTACは今回の敵3両だけを1両ずつ照射し、撃破後は次の見通せる指定敵へ切り替えます。
見通しが成立しない対象には照射できません。依頼中は見通しを再確認し、条件が戻れば照射を再開します。
Stop laser後は新しい依頼まで再開しません。全3両破壊や任務終了でも停止します。
自動照射ができなくても任務は継続し、自機センサー・自機照射で敵を破壊できます。
敵3両破壊後のBLUE基地/対応空母への帰還と、各自150/90/0の採点は従来どおりです。

正常に接続済みのtraining-17.3用Hookはそのまま使います。今回の更新でHook再導入や成績初期化は不要です。
ZIPに入っていないserver配下のLua部品をHookへコピーしないでください。

検証: 自動624ケースと全結合検証、隔離した実DCSで3コードの待機・依頼・停止・再依頼、レーザー点一致・回収を確認。同梱のDCS_CHECK.logに記録しています。
ApacheのLST表示、Hellfire命中、長時間サーバー運用は実ゲーム確認待ちです。
以前報告された手前への着弾が解消したと保証する検証ではありません。

戻す場合は、バックアップした旧.mizへ戻してミッションを再開始します。

短縮ブリーフィング版: 受注/Statusは味方MGRS、敵の特徴、待機とコード/依頼案内、目標、報酬、人数の7行です。照射制御は先のtraining-18.1と同一で、同梱DCS_CHECK.logはその照射制御の検査記録です。
